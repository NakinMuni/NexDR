# NexDR

**คลังความรู้การลงทุน + เครื่องมือช่วยวิเคราะห์ ตั้งแต่ระดับเริ่มต้นถึงระดับกลาง**
เริ่มจากการเช็คราคาที่เหมาะสม (Fair Value) ของ DR ในตลาดหุ้นไทย แล้วค่อยๆ ขยายเป็นเครื่องมือการเงินและคู่มือสำหรับมือใหม่

## NexDR คืออะไร

DR (Depositary Receipt) คือใบรับฝากที่ซื้อขายในตลาดหุ้นไทยด้วยเงินบาท โดยอิงราคาหุ้นหรือ ETF ต่างประเทศ ราคา DR บนกระดานมักเบี่ยงจากราคาที่ "ควรเป็น" ตามหุ้นแม่และค่าเงิน NexDR ช่วยคำนวณส่วนต่างนี้ให้ดูง่าย โดยออกแบบให้ **มือใหม่ใช้ได้** ทั้งบนคอมและมือถือ

โปรเจกต์นี้ตั้งใจให้เป็นมากกว่าเครื่องคิดเลข DR คือเป็นพื้นที่รวบรวมความรู้และเครื่องมือด้านการลงทุนไว้ที่เดียว

## มีอะไรบ้าง

| หน้า | ทำอะไรได้ |
|---|---|
| 🏠 **หน้าแรก** | สรุปสถานะวันนี้ DR ที่ถูกกว่าหุ้นแม่มากสุด และพาดหัวข่าวตลาดหุ้นไทย/ตลาดโลก |
| 📊 **กระดาน** | รายการ DR ทั้งหมด ค้นหา กรองตามโซนราคา หมวดธุรกิจ ค่ายผู้ออก และตลาดอ้างอิง |
| ⭐ **เริ่มวิเคราะห์** | เฉพาะ DR ที่ติดดาว ดึงราคาสดได้ พร้อมแจ้งเมื่อถึงราคาเป้าหมายส่วนตัว |
| 🧰 **เครื่องมือ** | DCA / ดอกเบี้ยทบต้น, เงินปันผล, ต้นทุนเฉลี่ย, ตารางผ่อนและโปะหนี้, Snowball vs Avalanche, DTI |
| 📖 **คู่มือ** | คู่มือการใช้งาน NexDR และคู่มือการลงทุนสำหรับมือใหม่ (พร้อมคำศัพท์) |

ในแต่ละตัว DR ใช้เครื่องคิดเลขจำลองได้ ใส่งบเป็นบาทแล้วดูว่าซื้อได้กี่หน่วย (รวมเศษหุ้น) และจดบทบาทในพอร์ต ราคาเป้าหมาย และโน้ตส่วนตัวได้

## วิธีอ่านราคา

```
Fair Value  =  ราคาหุ้นแม่  ×  อัตราแลกเปลี่ยน (เป็นบาท)  ÷  Ratio
ต่ำกว่า Fair 1 ช่วง =  Fair Value ลบ 1 ช่วงราคา (Tick Size)
```

- 🟢 **ถูกกว่า Fair Value** – ราคา SET ต่ำกว่าหรือเท่าระดับ "ต่ำกว่า Fair 1 ช่วง"
- ⚪ **ใกล้ Fair Value** – ใกล้เคียง Fair Value
- 🔴 **แพงกว่า Fair Value** – แพงกว่าราคาที่ควรเป็น

เป็นเครื่องมือช่วยเทียบราคาเท่านั้น ไม่ได้บอกว่าหุ้นตัวนั้นดีหรือควรซื้อ

## ข้อมูลส่วนตัวเก็บที่ไหน

รายการติดดาว ราคาเป้าหมาย และโน้ต **เก็บในเบราว์เซอร์ของแต่ละเครื่อง** ไม่ถูกส่งขึ้นเซิร์ฟเวอร์ เครื่องมือการเงินคำนวณในเครื่องผู้ใช้ทั้งหมด หากต้องการย้ายเครื่องให้ใช้ปุ่มสำรอง/กู้คืนข้อมูลในหน้า 📖 คู่มือ

## ติดตั้งเป็นของตัวเอง (สำหรับนักพัฒนา)

NexDR ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง ใช้ **GitHub Pages** (หน้าเว็บ) + **Google Apps Script** (ดึงราคา) + **Google Sheets** (รายชื่อ DR)

### 1) เตรียม Google Sheets

สร้างชีตชื่อ `DR` แถวแรกเป็นหัวตาราง ข้อมูลเริ่มแถวที่ 2

| คอลัมน์ | ความหมาย | ตัวอย่าง |
|---|---|---|
| A | ชื่อ DR | `AAPL80` |
| B | Ratio | `1:1000` หรือ `1000` |
| C | ตลาดอ้างอิง | `NASDAQ` |
| D | สัญลักษณ์หุ้นแม่ (รูปแบบ Yahoo Finance) | `AAPL` |
| E | สกุลเงินของหุ้นแม่ | `USD` |
| F | หมวดธุรกิจ (ไม่บังคับ คั่นด้วย `,`) | `เทคโนโลยี` |

ราคา DR บน SET ดึงจากชื่อ DR + `.BK` และอัตราแลกเปลี่ยนจากคู่เงิน `สกุลเงิน` + `THB`

### 2) ติดตั้ง Apps Script

1. ในชีตเปิดเมนู Extensions → Apps Script (ต้องสร้างสคริปต์จากชีตนี้ เพื่อให้สคริปต์อ่านชีตได้)
2. วางโค้ด `Code.gs` ในโปรเจกต์ แล้วบันทึก
3. เลือกฟังก์ชัน `setupTriggers` แล้วกด Run หนึ่งครั้ง เพื่อตั้งเวลาดึงทั้งตลาดวันละ 2 รอบ (ระบบจะขอสิทธิ์ให้อนุญาต)
4. Deploy → New deployment → เลือกประเภท Web app ตั้ง Execute as เป็น *Me* และ Who has access เป็น *Anyone* แล้วคัดลอก URL ที่ได้

*(ชื่อเมนูอาจต่างเล็กน้อยตามภาษาของ Google Account)*

### 3) ตั้งค่าหน้าเว็บ

เปิด `index.html` แล้วแก้ค่าคงที่ `GAS_API_URL` ในส่วน `<script>` เป็น URL ที่ได้จากขั้นตอนก่อนหน้า จากนั้นอัปโหลดขึ้น GitHub แล้วเปิด Settings → Pages เพื่อเปิดใช้งานเว็บ

### โควตาและการดึงราคา

บัญชี Google ฟรีมีโควตา `UrlFetch` ราว 20,000 ครั้งต่อวัน (ตัวเลขอาจเปลี่ยน ตรวจสอบกับเอกสาร Google ล่าสุด) NexDR จึงออกแบบให้ประหยัด:

- ดึงทั้งตลาดตามเวลาที่ตั้งไว้ (ค่าเริ่มต้นวันละ 2 รอบ) แล้วเก็บเป็นแคชในชีต
- ดึงสดเฉพาะ DR ที่ผู้ใช้ติดดาว และแคชราคา 5 นาที ใครกดซ้ำในช่วงนั้นไม่ยิงข้อมูลเพิ่ม
- ข่าวแคช 30 นาที

ถ้ามีผู้ใช้จำนวนมาก ควรปรับรอบเวลาและขนาดแคชในไฟล์ `Code.gs` (`LIVE_CACHE_SEC`, `NEWS_CACHE_SEC`)

## โครงสร้างโปรเจกต์

```
index.html   หน้าเว็บทั้งหมด (HTML + Tailwind CDN + JavaScript)
backend/Code.gs   สำเนาโค้ดฝั่ง Google Apps Script (ดึงราคา แคช ข่าว อีเมลเตือน) เก็บไว้สำรอง รันบน GitHub ไม่ได้ ต้องวางใน Apps Script
content/     เนื้อหาคู่มือ (แยกจากโค้ด แก้ได้โดยไม่ต้องแตะ index.html)
  index.txt      รายการคู่มือที่แสดงเป็นการ์ด
  glossary.txt   คลังศัพท์ (บรรทัดละคำ: ศัพท์ | ความหมาย)
  nexdr.txt, risk.txt, ...  คู่มือแต่ละเรื่อง (เขียนแบบ Markdown แบบย่อ)
```

## เพิ่มคู่มือใหม่ (ไม่ต้องแก้โค้ด)
1. สร้างไฟล์ `content/ชื่อ-ภาษาอังกฤษ.txt` เขียนเนื้อหาด้วย `## หัวข้อ`, `- รายการ`, `1. รายการเลข`, `> กล่องเตือน`, `**ตัวหนา**`, `[ข้อความ](ลิงก์)`
2. เพิ่มหนึ่งบรรทัดใน `content/index.txt` (ไอคอน | ชื่อ | ประเภท | วันที่อัปเดต) การ์ดจะขึ้นเองในหน้าคู่มือ
3. ประเภทมี 4 แบบ: ความรู้พื้นฐาน, มุมมองส่วนตัว, อ้างอิงแหล่งภายนอก, คู่มือใช้งาน เพื่อให้ผู้อ่านแยกข้อเท็จจริงออกจากแนวคิดส่วนตัวได้

## แผนที่อยากทำต่อ

- เครื่องมือกลุ่มวางแผนการเงิน (เงินสำรองฉุกเฉิน งบ 50/30/20 เป้าหมายเงินล้าน)
- คู่มือการลงทุนเพิ่ม: การอ่านงบการเงิน แนวคิดการลงทุน การบริหารความเสี่ยง
- ขยายคลังคำศัพท์
- พอร์ตจำลอง (เก็บข้อมูลในเครื่องผู้ใช้ มีสำรอง/กู้คืน)

ข้อเสนอแนะหรือแนะนำเนื้อหาเพิ่มเติม เปิดที่แท็บ Issues ได้เลย

## English summary

**NexDR** is a beginner-friendly web app that compares the price of Thai Depositary Receipts (DRs) on the SET with the fair value implied by the underlying foreign stock, and bundles a small knowledge base and a set of personal-finance calculators (DCA / compound interest, dividends, average cost, loan payoff, snowball vs avalanche, DTI).

It runs without a server of its own: a static `index.html` on GitHub Pages, a Google Apps Script backend (`Code.gs`) that fetches quotes and caches them in a Google Sheet, and a Sheet that lists the DRs. See the Thai setup guide above; the sheet columns are `DR | Ratio | Market | Parent ticker (Yahoo format) | Currency | Sectors`.

Educational use only. Not investment advice. Quotes come from an unofficial Yahoo Finance endpoint and may be delayed or inaccurate.
